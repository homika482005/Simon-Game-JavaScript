# 🎮 Simon Says Game

An interactive memory-based game built using **HTML, CSS, and JavaScript** where players repeat an increasingly complex sequence of colors.

## 🎮 How to Play

### On Desktop

1. Open the game.
2. Press any key or click **Start Game**.
3. Watch the sequence shown by Simon.
4. Click the buttons in the same order.
5. Each successful round adds a new color to the sequence.
6. Continue remembering the sequence as the level increases.
7. Clicking the wrong color ends the game.

### On Mobile

1. Open the game on your phone.
2. Tap **Start Game**.
3. Watch the color sequence.
4. Tap the buttons in the same order.
5. Continue until you make a mistake.

## 🧠 Game Logic

The game uses two arrays to manage the sequence:

```javascript
gameSeq
```

Stores the sequence generated by Simon.

```javascript
userSeq
```

Stores the sequence entered by the player.

For every new level:

1. A random color is added to `gameSeq`.
2. The complete sequence is displayed to the player.
3. Player input remains disabled while the sequence is playing.
4. Input is enabled after the sequence finishes.
5. Every player selection is compared with the corresponding Simon selection.
6. A correct sequence moves the player to the next level.
7. An incorrect selection ends the game.

---

## 🏆 Score & High Score

The game tracks the player's current score during gameplay.

The highest score is stored in the browser using:

```javascript
localStorage
```

This allows the high score to remain available after refreshing the page.
